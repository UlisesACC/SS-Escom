# SS-Escom

Ejemplo didáctico de simulación de un dosel vegetal con [Helios](https://plantsimulationlab.github.io/Helios/).

En [`simulacion_helios`](simulacion_helios/README.md) se incluyen la generación de una escena 3D, un experimento de radiación solar a tres elevaciones y una gráfica de los resultados. Las instrucciones explican cómo compilar y ejecutar en Windows o Linux.
